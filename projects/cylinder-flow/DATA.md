# 数据准备与获取条件

原始初场来自竞赛提供的算例。当前仓库不重新授权或分发这些原始数据，输入按
外部资料管理。请自行从资料拥有者取得有授权的原始归档。

- 输入数量与尺寸：1 文件，224,072 字节。
- 文件身份：data/manifest.json，含相对文件名、字节数、SHA256 和归档成员名。
- 角色：原始初场；参考终场只用于结果对照。
- 本地位置：data/external/，已被 Git 忽略。

```powershell
python reproduce.py import-data --archive "PATH_TO_AUTHORIZED_SUBMISSION.zip"
```

当前导入器识别最终归档的精确 SHA256，不会下载或运行外部软件，不会全量解压归档。
已有文件相同则复用，不同则报错。也可按清单手工放入自己合法取得的相同输入；
run 入口仍会校验每个文件。不要修改清单让未知数据绕过检查。

没有完整数据时仍可构建程序、执行数值内核测试、核对 results/ 中的历史结果和重绘
自有输出图；完整物理工况复现需要满足上述输入条件。

# 资料、来源与发布范围

当前仓库是供作者审阅的本地版本。尚未指定仓库范围的公开再分发许可证；继承的
项目源码保留其现有权利状态，见各项目 `LICENSE.md`。确定许可后再更新元数据与本文。

## 当前收录范围

- 项目自身的计算源码、独立包装脚本、构建与运行说明。
- 历史运行产生的结果记录、数值对照表、项目制作的图表和验证摘要。
- 对外部输入的文件名、尺寸、SHA256、来源说明及导入工具。

大型原始算例、参考终场、商业软件安装文件、运行库、许可证材料和私人研究记录
不在待提交的 Git 内容中。第三方数据的清单与派生结果不赋予原文件新的再分发许可。
原竞赛完整归档仍由其拥有者在原位置保管，本仓库不修改或重新分发完整归档。

## CFD 结果来源

初始输入与参考值来自竞赛提供的圆柱绕流和 M6 机翼材料；参考程序版本为
Fluent 25.1。独立程序和结果固定到各项目记录的源码版本。原输入按外部资料管理，
通过授权归档导入；获取不到输入时，可以进行源码构建、数值测试和保存结果核对。

依赖 GCC/Clang/MSVC、CMake、MPI 及可选 Python 库由使用者环境提供，遵循各自许可。
无需商业求解器即可构建和运行所附独立程序。公开介绍与必要的数据/依赖来源说明
分工明确，不以产品商标暗示任何厂商背书。
